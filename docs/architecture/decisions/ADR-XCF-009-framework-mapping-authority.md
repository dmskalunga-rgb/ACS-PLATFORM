# ADR-XCF-009: Framework mapping authority

Status: `APPROVED`

## Context

Cross-framework equivalence is interpretive and changes over time.

## Decision

Mappings are versioned governed assertions with source facts, mapping type, direction, confidence,
rationale, reviewer/authority, effective time and supersession lineage. A mapping never rewrites
the original framework fact.

## Consequences

Unreviewed or stale mappings cannot become canonical or active.
